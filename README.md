# Übung 1 – Sentimentanalyse mit fastText

## Ziel
Trainieren eines Modells zur Klassifikation von Tweets aus dem Sentiment140-Datensatz in drei Klassen:
- Positiv
- Neutral
- Negativ

## Vorgehen
1. Datenformatierung mit `prepare_data.py`
2. Aufteilung in Trainings-, Entwicklungs- und Testdaten
3. Modelltraining mit fastText (`train_model.py`, `train_model_two.py`)
4. Evaluation mit F1-Score
5. Visualisierung der Confusion-Matrix (`confusion_matrix.py`)

## Ergebnisse
- Beste F1-Score (Dev): z. B. 0.8123
- Beste F1-Score (Test): z. B. 0.7834
- Confusion-Matrix gespeichert als `confusion_matrix.png`
